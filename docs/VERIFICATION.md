## Browser workflow

```bash
npm install
npx playwright install chromium
npm run test:browser
```

The portable Playwright script starts a fresh temporary SQLite world on port 8022. It checks:

- Guided critical-trauma dispatch; 4/4 fleet becomes 3/4; ICU rejection visible.
- A road closure excludes the closed edge; hospital unavailability reroutes Apollo First Med H15 to Vijaya H08; two reroutes recorded.
- Five-card rankings in both care and directory scope.
- Coordinate pickup near Alwarpet, chosen MIOT H03 destination and mocked browser geolocation.
- Hospital edit draft survives a five-second poll; another browser sees shared state.
- Algorithm cost agreement, journey arrival/completion and ambulance release; JSON report download.
- Directory MIOT search, return comparison, zoom, dark/light theme and 390px mobile layout without document overflow.
- All 868 map records, independent response/transport/return legs, return-to-base, eastbound scenario, street closure avoidance, map hospital search and road playback.
- No browser JavaScript errors during this workflow.

`docs/browser-verification.json` records results. PNG screenshots and `sample-demonstration-report.json` are generated by the script. They are **local** evidence, not AWS deployment proof. The geolocation check is mocked and does not prove real device GPS precision.
